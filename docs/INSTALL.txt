STEP 1: INSTALL
───────────────
Drag the SarcAsM app to your Applications folder


STEP 2: REMOVE SECURITY BLOCK (One-time setup)
───────────────────────────────────────────────

macOS will block the app because it's not code-signed ($99/year).
You need to run ONE command in Terminal:

1. Open Terminal:
   - Press Command+Space
   - Type: Terminal
   - Press Enter

2. Copy and paste this command:

   xattr -cr /Applications/SarcAsM-v*.app

3. Press Enter

4. Open SarcAsM normally from Applications!


WHY IS THIS NEEDED?
───────────────────
This is free academic software. Apple's code-signing costs $99/year,
which isn't feasible for open-source research tools.

Many scientific apps work this way: ImageJ, Fiji, R tools, etc.
